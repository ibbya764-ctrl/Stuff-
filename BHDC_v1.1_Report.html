BHDC v1.1 — Implementation & First Empirical Read

Branching Hamiltonian Dilation Collapse: the corrected coherent core, the GR geometry coupling, the entangled two-sector state, and the combined model — built, validated, and run.

CP² AI program · prepared 25 June 2026 · runs on CPU (torch 2.12.1); full-scale / multi-seed runs reserved for the workstation GPU. Branch claude/bhdc-v1-1-implementation-4bklfy, PR #1.

One-line status. The whole architecture from the working paper is implemented behind per-component flags and passes three validation gates. The first empirical reads are on-thesis: at matched budget the coherent (interfering) collapse is the only collapse arm that generalizes above chance, and the combined all-on model trains stably with the entanglement entropy settling at a stable nonzero value rather than collapsing. These are single-seed onset signals, not finished groks — honest caveats throughout.

2 · Validation gates ALL GREEN

The paper's step-1 bug-gate (§9.1) — run before any large commit.

Core (test_bhdc.py)

  • Parallel scan == sequential to machine tolerance: max|err| ≤ 5e-7 for T ∈ {1,2,8,17,64}. The O(T·logT) Hillis–Steele scan is validated against the O(T) reference before use (§7.2).
  • Geometry bank unitary (Identity / Torus / SU(2)-block / Mesh) to ≤5e-7 — the coherent sum is well defined (§3.4).
  • Encoder unit-norm; branch 0 pinned to the identity scenario (scale=1, phase reference); all 8 collapse×nonlin flag combos forward + backprop with finite grads.

Entanglement (test_entangled.py)

  • ‖M‖F = 1 at every r — bounded by construction, no SVD, no norm blow-up (§5.3).
  • r = 0 → product state (S < 0.1% of max); r large → entangled (S → log K); entropy monotone in r.
  • UA, UB unitary; reduced-state eigenvalues == Schmidt occupations; finite grads in both bases.

Combined (test_combined.py)

  • Every flag combination trains; flags toggle the right telemetry channels; the eigen entangled ladder follows the live spine spectrum (the operator literally in the wave function, §5.4); gates fire on NaN loss/grad, product-state entanglement, and router collapse.

3 · Matched-budget A/B — the decisive isolation KEY RESULT

The four collapse arms at identical p / split / steps / width / seed. Parameters are identical across arms (every branch, gate, and phase head is always built; the flag only changes the forward contraction), so the budget is matched by construction. p = 31, 1500 steps, AdamW lr 5e-3 wd 0.5, seed 0, chance = 0.032.

Only the coherent arm generalizes above chance. Single-scenario and the incoherent mixture both sit at val 0.0. This isolates the architecture's central claim (§3.3): it is the inter-branch coherence — the interference terms a softmax gate or a decohered mixture cannot reproduce — that carries the signal, not multi-scenario averaging. coherent > coherent-complex matches the paper's note that complex amplitudes train twitchier. 5 · Corrections carried from v1.0

  • Collapse last. Phase is carried through the spine and geometry; the single Born-rule |·|² happens once at the end of the block (v1.0 squared early and stripped the phase the spine exists to use).
  • One operator, not a bank. Branches differ only by a scalar zoom sb and a unitary geometry gb — the same spine seen many ways — replacing v1.0's per-branch GUE-perturbed Hamiltonians.
  • Coherent, not incoherent, collapse (§3 above), now empirically the load-bearing piece.
  • Two implementation bugs fixed during this build: the spine scan's phantom time-axis indexing, and the encoder normalizing only the real part.

6 · Honest status & next actions

Done, validated, runnable on CPU: coherent core + collapse arms + parallel scan + GR geometry coupling + telemetry; the entangled §5 block; the combined model + §8 gates; the grokking harness; the matched-budget A/B; the combined demo. Three validation gates green.

Needs GPU / matched budget (harness is ready — only compute is missing):

  • Trained leave-one-out attribution across core / +geometry / +entanglement / all-on — the flags + telemetry exist for exactly this.
  • The §5 eigen vs generic entanglement-basis trained contrast (numerics validated, training comparison not run).
  • The ~100M run (§9), sized d_model ≈ 720 / ~14 layers.

Deferred by the paper: hyperbolic/squeeze geometries (v2 — firewall question of whether negative-curvature branches interfere); exp-of-squeezing entanglement (v2 — needs a Gaussian-optics simulator). Firewall held throughout: GR/QM structure is used only as the functional form of inductive biases, never as a physical claim; nothing here touches the Riemann hypothesis.
